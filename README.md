# Apex Auction House

The house's own auction floor for pre-built properties — a venue of
**Apex Air Solutions**, built by **Apex Ground Crew** (Ground Crew builds,
the House sells).

Plain static files, vanilla HTML/CSS/JS, no build step:

- `index.html` — the floor: Drop № 1 (Lot № 1, apexairsolutions.shop),
  the queue, the lot board, house rules, all gates in one hall, the
  name-intent door, the community panel.
- `rubric.html` — the Rubric on the Wall: the house's published valuation
  method and its honest limits.
- `style.css`, `site.js` — the flavor-map surface (glass panels over a
  hero ground) and the strip fittings (live clock + live weather read).

House law on this floor: every valuation is labelled an estimate; the
engine licence is disclosed before money moves; money is always stated
in calm amber, never red (the Amber Law).
